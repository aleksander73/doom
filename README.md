# Doom

Doom is a game clone prototype of the legendary <a href="https://en.wikipedia.org/wiki/Doom_(1993_video_game)">Doom (1993)</a> game developed by id Software.

The project has been developed using my own <a href="https://github.com/aleksander73/vector">Vector</a> game engine written in Java & OpenGL ES.
